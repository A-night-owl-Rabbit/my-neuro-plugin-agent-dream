# Agent Dream（梦系统）

> [my-neuro(肥牛)](https://github.com/morettt/my-neuro) 社区插件发布仓库 · 需要 MemOS 记忆后端 · 当前版本：1.1.0

**my-neuro** 生态下的 **live-2d 社区插件**：在深夜静默窗口内，让数字角色进入「仿生梦境」——结合 MemOS 记忆做语义涟漪与联想，生成第一人称意识流梦叙事；可选「梦中图书馆」好奇心检索；梦醒后可提取关键词、梦残像，并按重要度写入长期记忆或仅落盘为本地文本。梦中若触发记忆整理，相关删除/合并等操作走审批窗口，避免误伤重要记忆。

## 这是什么？（给完全没接触过的小白）

- **插件**：给肥牛加功能的"扩展包"，放进插件文件夹、重启一次就生效
- 简单说：**给你的 AI 造一个会做梦的深夜**。到了配置的时间段（默认 23 点~6 点），你不再说话、机器也安静一阵后，肥牛会犯困、说要去睡了——然后真的"睡着"，基于你们最近的聊天记忆做一个第一人称的梦
- 梦会写成本地 txt 存下来；醒来后她可能跟你说「刚才梦到 xx」，重要度的梦还会沉淀进长期记忆
- 有个彩蛋玩法叫**梦中图书馆**：梦里偶尔会出现一座图书馆，允许她"查一件白天好奇的事"，答案会变成她的私人知识（需要配好 kimi-search 等搜索插件）
- 梦里的记忆整理操作（合并/归档）都会**弹审批窗口让你确认**，不会背着你动记忆

## 功能概览

| 能力 | 说明 |
|------|------|
| **静默入梦** | 可配置时间段、冷却、概率、静默分钟数等，避免活跃对话中突然入梦 |
| **晚安快速通道** | 检测晚安后延迟再进入犯困流程，便于与其他插件错峰 |
| **记忆涟漪引擎** | 从近期/中期/深层记忆抽样与语义联想，构造梦境输入 |
| **独立梦境 LLM** | 可配置单独的 API URL、Key、模型与温度，与主对话模型解耦 |
| **本地梦日志** | 叙事与图书馆记录写入可配置目录（模板默认为相对路径 `./exported-dreams`） |
| **梦中图书馆** | 可选 `dream_curiosity_search`，依赖已配置好的搜索类插件（如 kimi-search） |
| **梦后处理** | 关键词、重要度、梦残像；达标写入 MemOS，低分仅本地文件 |
| **入梦气泡 UI** | 气泡位置与缩放可在配置中调节 |

## 环境要求

- 与 **my-neuro** `live-2d` 一致的 **Node.js** 运行环境  
- 已启用并正确配置 **MemOS**（记忆检索与写入依赖主程序与 MemOS 服务）  
- 若启用梦中检索：需 **kimi-search**（或兼容协议）等插件与对应 Key

## 安装教程

**方式一（推荐）：WebUI 插件广场一键安装**

1. 打开 my-neuro 的 WebUI 控制面板 → 「广场」→ 插件广场
2. 找到本插件，点击安装（已装过则点更新）
3. 重启 Live2D 桌宠

**方式二：手动安装**

将整个插件目录放到 my-neuro 的社区插件路径下，例如：

```
live-2d/plugins/community/agent-dream/
```

目录内应包含 `index.js`、`metadata.json`、`plugin_config.json` 以及本仓库中的各模块文件。

在 my-neuro 中启用插件后，按界面提示重启或重新加载插件。

## 配置说明（`plugin_config.json`）

**本仓库中的 `plugin_config.json` 为公开模板：`dream_api_key` 等敏感项为空，梦境人设为占位说明，请勿把填好真实 Key 或私人角色设定的文件提交到 Git。**

### 主要配置项（节选）

| 配置项 | 说明 |
|--------|------|
| `dream_system_prompt` | 梦境专用系统提示词，需自行填写角色与叙事规则 |
| `drowsy_prompt` / `wakeup_prompt_template` / `interrupted_prompt` | 犯困、醒来梦话、被打断时的系统侧引导 |
| `dream_api_url` / `dream_api_key` / `dream_model` | 梦境 LLM；Key 留空时可回退主对话 Key（视主程序行为而定） |
| `dream_save_folder` | 梦境 txt 保存目录，建议使用你有写权限的路径 |
| `time_window_*` / `dream_frequency_hours` / `probability` | 做梦时段与触发节奏 |
| `silence_threshold_minutes` | 用户无交互多久后才允许入梦（重要安全阀） |
| `enable_dream_curiosity` | 是否启用梦中图书馆工具链 |
| `auto_save_to_memos` / `dream_importance_threshold` | 梦后是否写入 MemOS 及阈值 |

### 编辑 JSON 时的编码

若保存为 UTF-8 带 BOM，可能导致主程序解析报错。建议使用 VS Code 等保存为 **UTF-8（无 BOM）**。

## 使用教程（照着做就行）

1. 装好 MemOS 后端并启用本插件，梦境 LLM 可直接用 WebUI 下拉选提供商（`dream_provider_id`/`dream_model_id`），或手填 `dream_api_url`/`dream_api_key`
2. 确认做梦时间窗口（默认 23~6 点）、做梦概率、静默门槛符合你的作息
3. 晚上睡前对肥牛说声「晚安」，她会走晚安快速通道犯困入睡
4. 第二天早上问她：「昨晚睡得好吗？做梦了没？」——她会告诉你梦见了什么
5. 到配置的「梦境保存目录」可以找到当天的梦 txt 原文

## 常见问题（FAQ）

- **她从不做梦？** 检查四件事：做梦时间窗口是否覆盖当前时段；做梦概率是否被调太低；静默门槛（默认 20 分钟内不能有交互）；MemOS 后端是否正常运行（梦的素材来自记忆）。
- **梦的质量很差/字数很少？** 确认梦境人设提示词（`dream_system_prompt`）已按你的角色填写完整；创意温度（默认 1.0）可微调；模型建议选长文写作强的。
- **梦里会乱删我的记忆吗？** 不会。梦中的记忆整理操作会弹审批窗口，由你逐条确认；低重要度内容按阈值归档而非删除。
- **不想被半夜说话吵到？** 醒来分享梦话开关（`wakeup_share` 类配置）可关；她入梦和醒来的台词都会走 TTS，也可在配置里改掉或清空。
- **没配 MemOS 能用吗？** 不行，记忆涟漪引擎的素材与梦后写入都依赖 MemOS；请先部署 my-neuro-memos-system。

## 故障排查

1. 日志搜 `dream`，可看到调度器状态（等待入睡/涟漪生成/梦后处理）
2. 入梦后没反应：查梦境 LLM 的地址/Key/模型名（或提供商下拉选择）是否有效
3. 还有问题请到 [本仓库 Issues](https://github.com/A-night-owl-Rabbit/my-neuro-plugin-agent-dream/issues) 提问

## 更新与卸载

- **更新**：插件广场点更新，或手动覆盖 `community/agent-dream/` 后重启；`dream_state.json` 与已保存的梦不会被删
- **卸载**：WebUI「插件管理」停用并删除插件文件夹；想留住梦就先备份「梦境保存目录」里的 txt
